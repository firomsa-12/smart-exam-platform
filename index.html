Import Questions







Import a JSON file or choose a TXT, text-based PDF, or DOCX Word document. Questions will be classified automatically using topic keywords, then you can review and correct every topic before saving.
First choose the document's subject above (Physics, Chemistry, Biology, Mathematics, English, or General), then import it. Questions extracted from that document will be categorized under the selected subject unless a JSON question specifies its own subject. When a student starts an exam or practice session, they can select the subject on the dashboard.
Each question needs four options (A–D). Correct answers can appear with each question or in an answer key at the end.
If no answer is supplied, the question is imported as ungraded until an answer key is added.
For text documents, use numbered questions and options such as A. option, B. option, C. option, D. option.




JSON example:

[
  {
    "question": "2 + 2?",
    "options": ["3", "4", "5", "6"],
    "answer": 1,
    "subject": "Mathematics"
  }
]

Text example:

1. What is 2 + 2?
A. 3
B. 4
C. 5
D. 6

2. Which planet is known as the Red Planet?
A. Earth
B. Venus
C. Mars
D. Jupiter

Answer key:
1. B
2. C
